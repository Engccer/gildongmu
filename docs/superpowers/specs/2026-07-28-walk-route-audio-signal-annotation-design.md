# 도보 경로 브리핑 음향신호기 주석 (2026-07-28)

## 배경·목표

보행 인프라 데이터(음향신호기)는 "내 주변" 반경 집계 형태로는 실보행 행동을 바꾸지 못한다(위원장 실사용 판정 2026-07-28). 데이터가 힘을 갖는 자리는 **도보 경로 위**다: Tmap 도보 브리핑의 횡단보도 단계에 "음향신호기 있음"을 주석으로 붙여, 출발 전 미리 듣기에서 어느 건널목에 음향신호기가 있는지 알 수 있게 한다.

- 측정 가능한 성과: 음향신호기 인접 횡단보도를 지나는 도보 브리핑에서 해당 단계 낭독만으로 신호기 유무를 알 수 있다(실호출 게이트로 확인).
- 반경 패널(`WalkInfraNearby`)·채팅 `get_walk_infrastructure`는 현행 유지(이 spec 범위 밖).

## 실측 근거 (2026-07-28, 길동 구간 원본 Tmap 응답 × OA-15543 seed 대조)

- Tmap 단계 description에 횡단보도 통과가 **"횡단보도" 리터럴로 명시**된다(예: "우마주 길동점에서 우측 횡단보도 후 보행자도로를 따라 11m 이동").
- 신호기 있는 횡단보도 단계의 Point 좌표 ↔ seed 최근접 거리: **4~15m**. 무관한 단계: **127~218m**. 분포가 완전 분리(중간지대 없음).
- 비횡단보도 단계가 신호기 옆(5m)을 지나는 경우 실재 → **반경만으로 매칭하면 오탐**. "횡단보도" 문구 게이트 필수.
- 신호기 없는 횡단보도 실재(최근접 193m) → "없음" 단정은 불가능(미등록 신호기 가능성). **positive-only** 표기가 정직한 계약.

## 매칭 규칙 (확정)

단계가 다음 **둘 다** 충족할 때만 주석:

1. `description`에 `"횡단보도"` 포함
2. 단계 Point 좌표 반경 **40m** 내 음향신호기 seed 존재(실측 상한 15m의 여유 배수, 노이즈 바닥 127m의 1/3)

표기: description 끝에 쉼표 흡수 — `"…11m 이동, 음향신호기 있음"` (헌장 §4 한 줄=한 객체, 구분자 쉼표). 조건 미충족 단계는 무주석(침묵). "없음"·"정보 없음"은 표기하지 않는다(positive-only — 3-state를 뭉개는 게 아니라, 등록 데이터의 반증 능력 한계를 정직하게 반영한 단방향 표기).

## 아키텍처 (A안 확정)

```
라우트(/api/route/walk) ─┐
                          ├─▶ src/lib/walk-route.ts (서비스, 신설) ─▶ tmap-pedestrian provider
채팅 get_walk_route ─────┘         │
                                   └─ audio-signals seed(findAudioSignalsNear 계열)로 주석 후 좌표 제거
```

- **`src/lib/walk-route.ts` 서비스 신설**(walk-infra.ts 패턴 동형): provider 호출 → 단계별 주석 → 단계 좌표 제거 후 반환. 라우트·채팅 모두 이 서비스만 호출(provider 직접 호출 금지로 전환).
- **provider(`tmap-pedestrian.ts`)는 순수 Tmap 정규화 유지**, 단 `normalizeTmapWalkRoute`가 단계 좌표(`coord`)를 내부 전달용으로 보존하도록 확장. seed import는 provider에 넣지 않는다(단일 책임).
- **API 응답 형태 불변**: 서비스가 반환 전 `coord`를 제거하므로 `/api/route/walk`·채팅 도구 data의 스키마는 기존과 동일(문장만 길어짐). **웹·iOS·CLI/MCP·채팅이 클라이언트 변경 0으로 자동 적용**(iOS 심사·CLI 재발행 불필요).
- 주석 판정은 seed 전체 필터가 아니라 단계 좌표 기준 최근접 1점 존재 여부만 필요 — `audio-signals.ts`에 경량 조회(반경 내 존재 여부)를 추가하거나 기존 `findAudioSignalsNear`를 재사용(구현 시 성능·단순성으로 택1, 좌표계·bbox 로직 재구현 금지).

## 경계·불변식

- **서울 bbox 밖**: seed가 null → 주석이 아예 안 붙음(positive-only라 부재가 "없음" 주장 아님). 별도 표기 없음.
- **언어**: 도보 경로는 V1 ko 전용 → 주석도 한국어 리터럴 1개(서비스 파일 상수). i18n 키 불필요.
- **기준일 각주 미표기**: 사용자 행동을 바꾸지 않는 정보([[honesty-disclosures-belong-to-api-layer]]). 등록 기준 안내는 보행 인프라 패널이 이미 담당.
- **캐시**: Tmap fetch revalidate 3600은 provider 내부 그대로. 주석은 fetch 후 매 요청 결정론 계산(추가 캐시 불필요).
- 채팅 `WALK_STEPS_CAP=20` 등 기존 방어 로직 불변. LLM은 주석 포함 문장을 그대로 받는다(날조 금지 원칙과 정합 — 도구가 준 필드).
