# 유휴 복귀 초기화 + iOS 제목 탭 리셋 설계

> 2026-07-18. 웹(PWA)·iOS 네이티브 공통: 앱을 10분 이상 사용하지 않다가 다시 접속하면 초기 화면으로 복귀한다. 추가로 iOS에 웹 헤더 제목 링크와 동형인 "제목 탭 → 처음으로" 동작을 도입한다.

## 배경·문제

- 장소를 검색하고 결과를 확인하면 그 화면이 계속 남는다. 사용 패턴상 이전 결과가 오래 남아 있을 이유가 없고, 재접속 시 스테일 화면이 먼저 보이는 것이 불편.
- 웹은 상태가 여러 곳에 흩어져 있다: `PlaceSearch` 검색 상태, `?q=` URL, History 스택(상세 뷰), 근처 패널 싱글턴 스토어, 채팅 오버레이.
- PWA 함정: iOS 홈 화면 앱은 프로세스 재시작 시 마지막 URL(`?q=검색어`)을 복원하고, 이 앱은 `?q=`가 있으면 자동 재검색한다. "백그라운드 복귀"뿐 아니라 "콜드 재시작" 경로도 함께 막아야 한다.
- iOS 제목: 웹 헤더 제목 '길동무'는 하드 내비 `<a href="/{locale}">`라 "처음으로 돌아가기"가 보장되지만(Header.tsx 주석 참조), iOS `navigationTitle("길동무")`은 표시 전용이라 탭 불가.

## 공통 원칙

- 마지막 사용 시각을 기록해 두고, 다시 활성화될 때 경과가 임계를 넘으면 초기 화면으로 복귀.
- 임계는 상수 `10분`(웹 `IDLE_RESET_MS = 10 * 60 * 1000`, iOS `idleResetInterval: TimeInterval = 600`).
- 초기화 방식은 "부분 상태 지우기(소프트 리셋)"가 아니라 **전체 재생성**: 웹은 하드 리로드, iOS는 뷰 트리 재생성. 흩어진 상태를 개별로 지우면 누락 시 "반쯤 초기화된 화면"이라는 더 나쁜 상태가 된다.

## 웹 (PWA)

`IdleReset` 클라이언트 컴포넌트 1개를 `[locale]/layout.tsx`에 마운트(`SWRegister`와 동형 패턴).

- **기록**: `visibilitychange`(hidden 전환)·`pagehide` 시 `localStorage`에 타임스탬프 기록. visible 복귀·첫 마운트 시에도 갱신(활동 표시).
- **판정**: visible 복귀 시와 첫 마운트 시, 저장된 타임스탬프가 10분보다 오래됐으면 리셋.
- **리셋**: `location.replace(쿼리 없는 로케일 홈)` — 전체 리로드. 검색·상세·History 스택·근처 패널·채팅 오버레이가 구조적으로 전부 초기화되고, 스테일 서비스워커가 새 배포를 픽업하는 계기도 된다. 10분 이상 자리를 비운 뒤라 리로드 비용은 체감되지 않으며, 스크린 리더 포커스는 문서 최상단 = 초기 화면에서 시작.
- **보존 경계**: 타임스탬프가 없으면(첫 방문·공유 링크 진입) 리셋하지 않는다 → `?q=` 공유·새로고침 보존 기능 유지. 스토리지는 `localStorage`(PWA 콜드 재시작에도 생존; sessionStorage는 복원 여부가 브라우저 재량이라 부적합).
- **판정 로직은 순수 함수로 분리**(`shouldIdleReset(storedTs, now)` + 리셋 대상 URL 계산) → Vitest 단위 테스트. 리로드 호출 자체는 jsdom 밖이므로 판정만 테스트.

## iOS (네이티브 SwiftUI)

`GildongmuApp`에 리셋 메커니즘 하나를 두고 유휴 복귀·제목 탭이 공유한다.

- **메커니즘**: `@State private var sessionEpoch = 0`, `TabView`에 `.id(sessionEpoch)`. epoch가 바뀌면 SwiftUI가 뷰 트리 전체(SearchModel·탭 선택 포함)를 재생성 → 초기 상태.
- **유휴 복귀**: `@Environment(\.scenePhase)` 감시. `.background` 진입 시각 기록 → `.active` 복귀 시 10분 초과면 `sessionEpoch += 1`.
- **제목 탭 리셋(웹 제목 링크 동형)**: 리셋 액션(epoch 증가 클로저)을 environment로 `SearchView`에 전달. 내비 바 `ToolbarItem(placement: .principal)`에 **Button("길동무")** — 탭하면 초기 화면 복귀. VoiceOver에는 "길동무, 버튼"으로 노출(웹의 제목 링크와 같은 의미 구조). `navigationTitle("길동무")`은 유지(상세 push 시 뒤로 버튼 라벨 보존), 표시 모드는 inline으로 고정해 principal 버튼이 중앙 표시를 대체.
- **범위**: "내 주변" 탭 제목(`내 주변`)은 앱 제목이 아니므로 그대로 둔다(미니멀). 리셋 결과는 항상 검색 탭 초기 화면.
- **판정 로직은 GildongmuKit 순수 함수**(`shouldIdleReset(backgroundedAt:now:)`)로 두어 기존 테스트 레인에 태운다.

## 에러·경계 처리

- 웹 `localStorage` 접근은 try/catch(사파리 프라이빗 모드 등 실패 시 기능 조용히 무동작 — 리셋은 편의 기능이지 정합성 요건이 아님).
- 리셋 판정에 걸리는 시점이 검색 진행 중이어도 문제없음: 리로드·재생성이 요청째 폐기.
- iOS `.inactive`(앱 전환기 노출 등)는 기록하지 않고 `.background`만 기록 — 잠깐의 인터럽션(전화·알림센터)으로 오리셋 방지.

## 테스트·검증

- 웹: 판정 순수 함수 Vitest 단위 테스트(경계: 정확히 10분, 타임스탬프 없음, 미래 타임스탬프).
- iOS: GildongmuKit 판정 함수 단위 테스트.
- 실기기 검증(머지 게이트): 웹 PWA·iOS 앱에서 검색 → 백그라운드 10분+ → 복귀 시 초기 화면, 10분 미만 복귀 시 상태 유지, iOS 제목 탭 시 즉시 초기 화면.
