# 장소 상세 주소 복사 버튼 배치 개선 설계

> 2026-07-01. 프로덕션 데스크톱·모바일 화면 감사 결과와 사용자 승인에 따라 확정한다.

## 배경

`PlaceDetail`의 주소 복사 버튼은 영문·한글 주소 두 줄 아래에 독립 행으로 놓여 있다. 주소와 가까워 의미 연결은 맞고 44px 터치 높이도 확보되어 있지만, 작은 보조 동작이 한 행을 차지해 주소와 전화번호 사이의 정보 읽기 흐름을 끊는다. 모바일에서는 실제 버튼 높이보다 라벨이 작아 빈 공간처럼 보이며 주소에 딸린 동작이라는 시각적 묶음도 약하다.

현재 화면 근거와 상세 감사는 `docs/audits/2026-07-01-place-detail-copy-button/`에 둔다.

## 목표

- 복사 버튼을 주소의 보조 동작으로 즉시 인식할 수 있게 한다.
- 주소 다음에 전화번호가 자연스럽게 이어지도록 정보 흐름을 복원한다.
- 기존 클립보드 동작, 성공 통지, 키보드 접근성, 44×44px 최소 터치 영역을 보존한다.
- 영문 주소가 없거나 보조 한글 주소가 없는 장소에서도 배치가 무너지지 않게 한다.

## 설계

### 구조

주소와 복사 버튼을 하나의 반응형 주소 블록으로 묶는다.

- 바깥 컨테이너: 주소 텍스트 묶음과 복사 버튼을 가로로 배치하는 `flex` 컨테이너.
- 주소 텍스트 묶음: 남은 너비를 사용하고 긴 주소는 자연스럽게 줄바꿈한다. 기존 단일 텍스트 단락과 `lang` 규칙을 그대로 유지한다.
- 복사 버튼: 주소 블록 오른쪽 상단에 배치하고 `shrink-0`으로 터치 영역을 보존한다.
- 전화번호: 주소 블록이 끝난 뒤 다음 정보 행으로 렌더한다.

### 버튼 표현

- 기존 `Copy` 아이콘과 로케일별 텍스트를 유지한다.
- 최소 높이 44px를 유지하고 최소 너비도 44px 이상이 되게 한다.
- 작은 보조 동작이라는 위계는 유지하되, 주소 블록 안에서 위치로 관계를 드러낸다.
- 복사 성공 통지는 기존 `role="status"` polite announcer를 유지한다.

### 접근성

- 읽기 순서는 주소 → 보조 한글 주소(있을 때) → 복사 버튼 → 전화번호를 유지한다.
- 주소 텍스트와 버튼을 하나의 접근성 객체로 합치지 않는다. 인터랙티브 요소는 별도 객체가 정상이라는 프로젝트 헌장을 따른다.
- 아이콘은 계속 `aria-hidden="true"`로 두고 버튼의 가시 텍스트를 접근 가능한 이름으로 사용한다.
- 주소 단락은 기존처럼 라벨과 값을 단일 텍스트 노드로 유지한다.
- 버튼은 키보드 포커스와 44×44px 터치 영역을 유지한다.

## 반응형 동작

- 데스크톱: 주소 텍스트 왼쪽, 복사 버튼 오른쪽 상단.
- 모바일 390px: 복사 버튼 너비를 고정하고 주소 텍스트만 남은 폭에서 줄바꿈한다.
- 매우 긴 주소에서도 버튼이 화면 밖으로 밀리거나 주소 위를 덮지 않는다.

## 구현 범위

- `src/components/PlaceDetail.tsx`의 주소·복사 버튼 마크업과 배치 클래스만 수정한다.
- 클립보드 함수, 번역 문구, 외부 API, 상세 화면의 다른 정보·동작은 바꾸지 않는다.
- 필요하면 순수한 배치 계약을 검증할 수 있는 작은 테스트 헬퍼 또는 컴포넌트 소스 계약 테스트를 추가한다. 현재 Vitest가 React 컴포넌트 렌더 레인을 제공하지 않으므로, 컴포넌트 배치는 lint·build와 실제 브라우저 검증을 최종 게이트로 삼는다.

## 검증

1. 기존 프로덕션 화면과 같은 장소를 데스크톱 기본 뷰포트에서 열어 주소 블록의 시각적 묶음과 전화번호 흐름을 확인한다.
2. 390×844 모바일 뷰포트에서 긴 영문 주소 줄바꿈, 버튼 44×44px 이상, 가로 오버플로 부재를 확인한다.
3. 복사 버튼을 클릭해 클립보드 값과 성공 상태 통지를 확인한다.
4. DOM 순서와 버튼의 접근 가능한 이름을 확인한다.
5. `npm run test:run`, `npm run lint`, `npm run build`를 통과한다.

## 비목표

- 주소 행 전체를 버튼으로 만들지 않는다.
- 복사 후 토스트를 새로 추가하지 않는다.
- 상세 정보 전체 레이아웃이나 지도·길찾기 버튼을 재설계하지 않는다.
