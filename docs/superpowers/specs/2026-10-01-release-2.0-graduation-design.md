# 길동무 2.0 — 자동차·대중교통 안내와 백그라운드 음성 안내의 정식판 졸업

2026-10-01 위원장 판정. 실험판에만 있던 자동차 안내·대중교통 안내(승차 전 도보·하차 뒤 도보 인계 포함)·백그라운드 음성 안내 토글을 정식판에 싣고 App Store 버전을 **2.0**으로 올린다. 나들이(E51)·햅틱 확장 스위치(E30)·탭 순서(K1 ①)·좌우 안내음 피커는 실험판에 남는다.

> 설계 리뷰 판정: 생략. 새 불변식·새 외부 통합이 없고(봉인 삭제는 기존 가드의 역방향), App Review 영향은 심사 노트 한 절 갱신뿐이다. 구현 리뷰는 커밋 뒤 별도 컨텍스트 서브에이전트로 한다.

## 2. 코드 변경

봉인은 "세션을 시작시키는 호출 전수"가 축이다(spec 2026-08-15 §3.2). 졸업은 그 표의 **차단 행을 도달 행으로** 바꾸는 것이고, 플래그는 삭제한다(항상 참 상수를 남기지 않는다).

| 자리 | 변경 |
|---|---|
| `AppConfig.experimentalGuidanceEnabled` | 선언 삭제 |
| `carGuideStartable` | 플래그 검사 삭제(ko ∧ Tmap 조건은 그대로 — 자동차 문장은 서버 ko 재작성) |
| `altTransitGuideStartable` | 플래그 검사 삭제(대중교통 시작 버튼은 추천·대안 모두 이 게이트를 지난다) |
| `transitGuideStartable`·`briefFallbackVisible`·간략 단독 시작 버튼(`beacon.briefGuideStart`) | **삭제**. 간략 안내는 모드가 아니라 내부 강등이고(E16 축2, CLAUDE.md "시작 가능 수단 0이면 버튼 0") 실험판에서만 남아 있던 단독 진입점이었다. 그 섹션의 버튼은 추적 중 "안내 종료" 한 얼굴만 남는다(`stopByUser`) |
| `AppConfig.experimentalBackgroundSpeechEnabled` | 선언 삭제. Kit `BackgroundSpeech.isEnabled(stored:)`에서 `available` 인자 삭제, 설정 행 조건 삭제 |
| 설정 "자동차 안내 듣는 사람" 피커 | `#if DEBUG \|\| EXPERIMENTAL` 밖으로. 라벨의 "(실험)" 삭제(6로케일) |
| 공지 | `WalkGuideNoticeSheet`(V1, `walkGuideNoticeV1`) → `ReleaseNoticeSheet`(`releaseNoticeV2`), 루트 `GildongmuApp`의 `.task`가 미확인이면 띄운다. V1 키·문자열 삭제 |
| 가드 | `guidance-gate-drift.test.ts`: 봉인 검사 → 졸업 검사(플래그 식별자 0건·`briefGuideStart` 0건), 진입점 수 8 → 7(간략 toggle 삭제), 수동 위치 고지 3 → 2. `background-speech-guard.test.ts`: 봉인 검사 삭제, 실효값 호출 형태 갱신 |
| 버전 | `MARKETING_VERSION` 2.0.0 · `CURRENT_PROJECT_VERSION` 29(3곳씩) |

진입점 전수(갱신 후 7곳): 도보 줄 시작(`session.startBeacon`) · 자동차 시작(`session.startBeacon`) · 정밀 위치 허용 뒤 재시작(`beacon.restart`) · `GuideSession.acceptWalkHandoff` · `acceptCarWalkHandoff` · `startTransit`(승차 전 도보) · `acceptOutingReturn`(나들이 봉인 안). 대중교통 세션 시작은 `altTransitGuideStartable` 게이트 뒤 `session.startTransit`.

## 3. 심사·개인정보

- 심사 노트 §9 백그라운드 절을 세 수단으로 넓힌다(자동차 임박 큐·대중교통 도착 관측과 keep-alive 위치 스트림의 쓰임). 새 권한·새 데이터 유형·새 제3자는 없다(위치·오디오 백그라운드 모드는 1.7부터, Tmap·ODsay·TOPIS는 브리핑에서 이미 쓴다). 개인정보 3자 일치는 점검만.
- 1.19가 아직 심사 중이면 2.0은 그 뒤 버전이고, 심사 취소됐으면 노트는 1.18 이후 전부다(스킬 0단계).
