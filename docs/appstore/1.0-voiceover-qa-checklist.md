# 길동무 iOS 1.0.0(빌드 3) 실기기 VoiceOver QA 체크리스트

기기: iPhone 13 Pro, VoiceOver 켠 상태로 전 항목을 한 세션에 진행한다. 실제로 도는 동선(첫 실행 → 검색 → 장소 상세 → 내 주변 → 길찾기 → 채팅 → 설정 → 횡단 확인) 순서로 배치했다. 실패한 항목은 체크박스 옆에 무엇이 어떻게 들렸는지 한 줄로 적어 둔다.

## 1. 첫 실행·동의 게이트

- [ ] 앱 최초 실행 → 홈 화면 진입, 검색 입력창에 접근 가능한 이름이 붙어 있다. **판정**: 입력창이 "검색" 등 이름으로 낭독되면 합격. (일반 스모크)
- [ ] 채팅 탭 최초 진입 → 동의 화면이 뜬다. **판정**: 제목 헤딩 → 전송 데이터 안내 → AI 답변 고지 → 대안 안내(동의 없이도 검색·내 주변 이용 가능) → 처리방침 링크 → 동의 버튼 순서로 낭독되면 합격. (출처: 게이트 6항목 ①)
- [ ] 동의 화면의 처리방침 링크를 탭한다. **판정**: 앱 언어와 같은 언어의 처리방침 웹 페이지가 열리면 합격. (출처: 게이트 6항목 ⑥)
- [ ] 동의 버튼을 탭한다. **판정**: 채팅 대화 화면으로 전환되고 포커스가 입력 필드에 안착하면 합격. (출처: 게이트 6항목 ②)
- [ ] 동의 직후 질문을 보내고 받아쓰기 홀드도 시도한다. **판정**: 평소 전송·홀드 플로와 다르지 않으면 합격. (출처: 게이트 6항목 ③)
- [ ] 설정 → AI 채팅 토글을 끈 뒤 채팅 탭에 재진입한다. **판정**: 동의 화면으로 돌아가고 전송이 되지 않으면 합격. (출처: 게이트 6항목 ④)
- [ ] 장소 상세 → "이 장소에 관해 물어보기" 시트를 연다. **판정**: 미동의 상태면 동일한 동의 화면이, 동의 후에는 위 항목들과 동일하게 동작하면 합격. (출처: 게이트 6항목 ⑤)
- [ ] 앱을 백그라운드로 10분 이상 두었다가 복귀한다. **판정**: 검색·채팅 등 상태가 초기 화면으로 리셋되면 합격. (출처: 유휴 복귀 초기화 2026-07-18)
- [ ] 앱을 백그라운드로 10분 미만 두었다가 복귀한다. **판정**: 이전 상태가 그대로 유지되면 합격. (출처: 유휴 복귀 초기화 2026-07-18)

## 2. 검색 탭

- [ ] 검색어를 입력해 제출한다. **판정**: 장소·주소·웹 3섹션이 순서대로 낭독되고 결과 수 통지가 한 번만 나오면 합격. (일반 회귀)
- [ ] 검색 입력 필드에 포커스를 준다. **판정**: 최근 검색 기록 목록이 낭독되고 항목 선택 시 재검색되면 합격. (출처: 최근 검색 기록 2026-07-26)
- [ ] 최근 검색 기록 항목을 iOS 로터로 삭제한다(스와이프 후 로터에 삭제 액션 노출). **판정**: 로터에서 삭제 액션이 뜨고 실행되면 항목이 사라지면 합격. (출처: 최근 검색 기록 2026-07-26)
- [ ] 위 삭제 직후 포커스 이동을 확인한다. **판정**: 다음 항목 → (없으면) 이전 항목 → (그것도 없으면) 검색 입력 필드 순서로 포커스가 이동하면 합격. (출처: 최근 검색 기록 2026-07-26)
- [ ] 홀드 마이크 버튼으로 음성 검색을 실행한다. **판정**: 누르고 있는 동안 VoiceOver 발화가 없고, 떼면 인식된 원문이 통지된 뒤 자동 검색되면 합격. (출처: 음성 받아쓰기 홀드 회귀, 2026-07-20 실기기 합격분 재확인)
- [ ] 단축어 "길동무 음성 검색"으로 앱에 진입한다. **판정**: 진입과 동시에 VoiceOver 커서가 마이크 행에 있어 스와이프 없이 바로 탭으로 정지할 수 있고, 녹음 중 발화가 없으면 합격. (출처: 단축어 2026-07-18, 음성 검색 정규화 2026-07-26)

## 3. 장소 상세

- [ ] 검색 결과에서 장소를 선택해 상세 화면에 들어간다. **판정**: 장소명이 헤딩으로 낭독되면 합격. (일반)
- [ ] 주소 복사 버튼을 탭한다. **판정**: 복사 완료 통지가 한 번 나오면 합격. (일반 회귀)
- [ ] 전화번호 행을 탭하거나 로터 액션으로 전화를 연결한다. **판정**: 전화 연결이 시도되면 합격. (일반 회귀)
- [ ] 장소 상세 화면에서 길게 눌러 나오는 메뉴(contextMenu)와 로터 커스텀 액션을 각각 확인한다. **판정**: 같은 동작(전화·지도 앱 연결 등)이 두 경로에 중복 노출되지 않으면 합격, 중복이면 실패로 기록. (출처: M6b 2026-07-10 잔여)
- [ ] 내 주변(소아 진료·아이 놀 곳·둘러보기·무장애 관광지) 목록에서 항목을 눌러 상세로 들어간다. **판정**: 검색 결과 상세와 같은 구성(주소 복사·전화·길찾기 프리필·채팅 진입)으로 낭독되면 합격. (출처: 내 주변→장소 상세 이식 2026-07-26)
- [ ] 위 목록 각 항목의 한 줄을 낭독시킨다. **판정**: 주소·전화·거리가 별도 줄로 쪼개지지 않고 한 접근성 객체로 낭독되면 합격. (출처: 내 주변→장소 상세 이식 2026-07-26)
- [ ] 소아 진료 상세 화면에 들어간다. **판정**: 진료 상태·찾아오는 길·달빛 지정 여부가 상세의 조건부 섹션으로만 낭독되고, 목록 단계에서는 지정 여부가 들리지 않으면 합격. (출처: 내 주변→장소 상세 이식 2026-07-26)
- [ ] 무장애 관광지 상세의 편의시설 섹션에 도달해 본다. **판정**: 헤딩 없이도 순서대로 도달 가능하면 합격, 찾기 불편하면 실패로 기록(헤더 추가 검토 신호). (출처: 내 주변→장소 상세 이식 2026-07-26, 무헤더 판단)
- [ ] 길찾기 화면 상단의 "현재 위치" 문구를 확인한다. **판정**: 도로명주소로 보정된 위치가 정확히 낭독되면 합격. (출처: 도보 길찾기 2026-07-22 잔여 미세 확인)

## 4. 내 주변

- [ ] 내 주변 탭에 진입한다. **판정**: 지하철·버스·따릉이 등 각 섹션이 구분되어 낭독되면 합격. (일반)
- [ ] 소아 야간진료 목록의 "더 보기" 버튼을 누른다. **판정**: 포커스가 방금 추가된 첫 새 항목으로 이동하고 별도 통지음 없이 조용히 넘어가면 합격. (출처: 더 보기 V1, 2026-07-27)
- [ ] 둘러보기·아이 놀 곳·무장애 관광지 목록에서도 각각 "더 보기"를 누른다. **판정**: 소아 진료와 동일한 포커스 계약(첫 새 항목 이동, 무통지)이면 합격. (출처: 더 보기 V2, 2026-07-27)
- [ ] 소아 진료 목록에서 지정(달빛) 태그와 소스별 반경 표기를 듣는다. **판정**: 중복·장황함 없이 한 줄에 자연스럽게 섞여 낭독되면 합격. (출처: 소아 진료 커버리지 확장 2026-07-26)
- [ ] 보행 인프라 패널을 연다. **판정**: 음향신호기·횡단보도·점자블록 그룹 헤딩 3개만 낭독되고 개별 지점은 무헤딩으로 지나가면 합격(의도된 설계). (일반 회귀, prod 2026-07-22)
- [ ] 단축어 "길동무 내 주변"으로 앱에 진입한다. **판정**: 내 주변 탭으로 바로 이동하면 합격. (출처: 단축어 2026-07-18)

## 5. 길찾기

- [ ] 길찾기 탭에서 경로를 조회한다. **판정**: 대중교통 → 자동차 → 도보 순서로 3수단 결과가 낭독되면 합격(이미 실기기 QA 통과분, 회귀 확인). (출처: 도보 길찾기+4탭 2026-07-22)
- [ ] 출발지·도착지 검색 필드에서 홀드 마이크로 받아쓰기를 실행한다. **판정**: 받아쓴 내용이 필드에 정상 반영되면 합격. (출처: 도보 길찾기 2026-07-22 잔여 미세 확인, 시트 홀드 받아쓰기)
- [ ] 역 상세의 첫차·막차 시간표 섹션을 듣는다. **판정**: 자동으로 낭독되고 익일 표기·기준 요일이 명확히 들리면 합격. (출처: 역 상세 보강 2026-07-22)
- [ ] 역 상세의 시설 보강 정보(음성유도기·엘리베이터 위치 폴백)를 듣는다. **판정**: 보강 실패 시에도 실패 사실을 숨기지 않고 안내되면 합격. (출처: 역 상세 보강 2026-07-22)

## 6. 채팅

- [ ] 채팅 탭에서 질문을 전송한다. **판정**: 스트리밍 중 포커스가 보내기 버튼에 머물고(추천 질문이 사라져도 이탈 없음) 합격. (출처: iOS 채팅 탭 포커스 계약 최종 판정, 2026-07-18/19)
- [ ] 답변 완료를 기다린다. **판정**: 포커스가 방금 보낸 질문 말풍선(헤딩)으로 이동하고, 다음 스와이프로 답변 첫 블록에 진입하면 합격. (출처: iOS 채팅 탭 포커스 계약 최종 판정, 2026-07-18/19)
- [ ] 답변 산문을 스와이프로 순회한다. **판정**: 헤딩·리스트·단락이 블록별로 낭독되고 통짜 한 덩어리로 들리지 않으면 합격. (출처: iOS 채팅 탭 2026-07-18)
- [ ] 답변 말미의 "듣기" 버튼으로 TTS를 재생한다. **판정**: 재생 중 다른 탭으로 전환하거나 장소 상세 시트를 열어도 무관한 재생이 죽지 않으면 합격. (출처: TTS 듣기·공유 2026-07-20)
- [ ] TTS 재생 중 홀드 마이크를 시작한다. **판정**: 재생이 먼저 멈추고 녹음으로 전환되면 합격. (출처: TTS 듣기·공유 2026-07-20)
- [ ] 답변의 "공유" 버튼을 탭한다. **판정**: 공유 시트가 정상 노출되면 합격. (출처: TTS 듣기·공유 2026-07-20)

## 7. 설정·다국어

- [ ] 제목 메뉴("길동무")를 연다. **판정**: "길동무, 팝업 버튼"으로 낭독되고, 새로고침 선택 시 현재 탭을 유지한 채 초기화되면 합격. (출처: 제목 메뉴·테마 2026-07-19)
- [ ] 설정에서 테마를 라이트/다크로 바꾼다. **판정**: 재시작 없이 즉시 반영되면 합격. (출처: 제목 메뉴·테마 2026-07-19)
- [ ] 설정 → AI 채팅 섹션에 진입한다. **판정**: 동의 토글·처리방침 링크·문제 신고 링크가 각각 별도 접근성 객체로 낭독되면 합격. (출처: App Store 필수 요건, 게이트 6항목 ④ 관련)
- [ ] 설정에서 언어를 English로 바꾼다. **판정**: 화면이 즉시 영어로 전환되고 설정 시트가 닫히지 않으면 합격. (출처: 다국어 2026-07-19)
- [ ] 언어를 English로 둔 채 채팅 질문과 받아쓰기를 시도한다. **판정**: 답변이 영어로 나오고 받아쓰기가 en-US로 인식되면 합격. (출처: 다국어 2026-07-19)
- [ ] 언어를 다시 한국어로 되돌린다. **판정**: 이전과 동일한 한국어 문구로 낭독되면 합격. (출처: 다국어 2026-07-19)
- [ ] 설정의 언어 선택 메뉴 피커를 연다. **판정**: 6개 언어가 각 언어의 자국어 표기로 낭독되면 합격. (출처: 다국어 2026-07-19, 일본어+메뉴 피커 2026-07-28)

## 8. 횡단(Dynamic Type·로터·전반)

- [ ] 시스템 글자 크기를 최대(200%)로 올리고 검색 필터 픽커·내 주변 펼침 패널을 조작한다. **판정**: 잘림·겹침으로 접근 불가한 컨트롤이 없으면 합격. (출처: M6b 2026-07-10)
- [ ] 무장애 관광지 등 펼침(DisclosureGroup) 패널을 연다. **판정**: 비동기 로드 완료 통지가 한 번만 발화하면 합격. (출처: M6b 2026-07-10)

## 합격 시 후속

이 체크리스트 전 항목 합격이 ASC 접근성 라벨의 VoiceOver "지원" 신고(`docs/appstore/1.0-submission-draft.md` §8, 판정 기준: 핵심 기능·첫 실행·설정 전부 VoiceOver 단독 완수)와 App Store 심사 제출 진행의 전제 조건이다. 실패 항목이 남아 있으면 신고·제출 모두 보류한다.
