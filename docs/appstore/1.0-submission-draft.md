## 2. 설명 (ko)

```
길동무는 시각장애인과 스크린 리더 사용자를 1급 시민으로 설계한 대한민국 길찾기 앱입니다. 검색부터 장소 정보, 경로 안내까지 전체 흐름이 VoiceOver만으로 완결됩니다.

주요 기능
- 장소·주소 검색: 카카오·네이버 기반 정확도순 결과, 분류·지역 필터
- 내 주변: 지하철 실시간 도착, 버스 도착, 따릉이, 소아 야간진료, 아이 놀 곳, 무장애 관광지, 둘러보기
- 현재 위치 정위: 지금 있는 곳을 문장으로 설명
- 경로 미리 듣기: 자동차·대중교통 경로를 출발 전에 텍스트 브리핑으로 확인, 실주행은 네이버지도·카카오맵으로 연결
- AI 채팅: 장소에 관해 무엇이든 질문(사용 전 데이터 전송 동의를 받고, 설정에서 언제든 철회 가능)
- 받아쓰기: 온디바이스 음성 인식으로 음성이 기기를 떠나지 않는 입력

접근성 설계 원칙
- 모든 정보는 리스트·텍스트가 정본이며 화면 요소 하나가 곧 하나의 낭독 단위입니다
- 헤딩 내비게이션으로 결과·대화를 빠르게 건너뛸 수 있습니다
- "0건", "정보 없음", "조회 실패"를 구분해 알려 줍니다

계정과 로그인이 없으며, 자체 서버에 개인정보를 저장하지 않습니다.
```

## 3. 설명 (en)

```
Gildongmu is a Korean navigation app designed with blind and screen-reader users as first-class citizens. The entire flow, from search to place details to route briefings, is fully usable with VoiceOver alone.

Features
- Place and address search with accuracy-first results and category filters
- Nearby: real-time subway and bus arrivals, bike share, night clinics, kid-friendly places, barrier-free attractions, surroundings
- Where am I: your current location described in plain sentences
- Route preview: car and transit briefings before you leave, with handoff to Naver Map or KakaoMap for actual navigation
- AI chat about any place (explicit consent before any data is sent, revocable in Settings)
- On-device dictation: your voice never leaves the phone

No account, no sign-in, and no personal data stored on our servers.
```

## 6. 연령 등급 (새 체계 질문 응답 가이드)

- 폭력·성적 콘텐츠·욕설·공포·도박·약물: 전부 "없음"

- 사용자 생성 콘텐츠/타 사용자와 상호작용: 없음
- 위치 공유(타인과): 없음(위치는 본인 조회용)
- AI 생성 콘텐츠: 채팅 답변이 AI 생성 — 해당 질문이 있으면 "있음"으로 정직 응답
- 예상 결과: 4+

## 7. 앱 개인정보(영양 라벨) 입력값

전 항목 공통: **수집함 / 사용자와 연결되지 않음(Not linked) / 추적 목적 아님 / 목적=앱 기능(App Functionality)**. PrivacyInfo.xcprivacy(2026-07-21 갱신본)와 1:1 일치.

| ASC 데이터 유형 | 근거 |
|---|---|
| 위치 > 정확한 위치 | 주변·경로·채팅 컨텍스트의 실시간 API 쿼리 |
| 검색 기록(Search History) | 검색어가 카카오·네이버·(0건 폴백)Perplexity로 전송 |
| 사용자 콘텐츠 > 기타 사용자 콘텐츠 | AI 채팅 질문·대화가 Gemini·Perplexity로 전송 |

"추적(Tracking)" 전체 질문: 아니오. 오디오는 신고하지 않음(iOS 받아쓰기 온디바이스, 음성이 기기를 떠나지 않음).

## 8. 접근성 라벨 (Accessibility Nutrition Labels)

- VoiceOver: **지원** 신고 — 근거는 실기기 통합 QA(완료 후 신고). 판정 기준: 핵심 기능·첫 실행(동의 화면 포함)·설정 전부 VoiceOver 단독 완수.
- 기타 항목(Larger Text 등)은 실기기 확인 후 지원 확정된 것만 신고(과대 신고 금지).

## 9. 심사 노트 (App Review Notes)

```
This app is built accessibility-first for blind and low-vision users; the developer is a blind screen-reader user. Reviewing with VoiceOver on will show the intended experience, but all features work visually as well.

- Location (when in use): used only for real-time queries of nearby places, transit arrivals, and route briefings. Not stored.
- Microphone: on-device dictation (iOS SpeechAnalyzer). Audio never leaves the device.
- AI chat (guideline 5.1.2(i)): before any chat data is sent, an inline consent screen names Google Gemini and Perplexity and requires explicit agreement. Consent can be revoked anytime in Settings > AI Chat. Declining does not affect search or nearby features.
- No account or sign-in. No demo credentials needed.
- Real-time transit data covers South Korea; use a Seoul location (e.g. 37.53, 127.14) to see subway/bus arrivals.
```
