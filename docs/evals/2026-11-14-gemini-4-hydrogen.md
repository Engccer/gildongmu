## 1. 무엇을 어떻게 쟀는가

- **모델**: 지금 채팅 모델 `gemini-3.6-flash`(생각 설정 없음), 후보 `gemini-4-hydrogen`. 후보는 생각 설정 없음(모델 기본값, 높음)과 「낮음」(`@low`) 두 가지로 쟀다. 베르길리우스는 지금 Google 기본 `gemini-3.5-flash-lite`(생각 최소)와 Hydrogen(생각 낮음. 최소는 400 오류)을 견줬다. 같은 날 모델 목록 API에서 셋을 확인했다.
- **단가**(공식 요금표, 2026-11-14 확인, 1M 토큰당 입력/출력): 3.6-flash $0.75/$3.75(2026-12-31까지, 2027-01-01부터 $1.50/$7.50), 4-hydrogen $1.50/$7.50(할인 없음), 3.5-flash-lite $0.30/$2.50. 비용 계산은 캐시 할인을 빼고 셌다(상한).
- **SDK**: 모든 실행이 `@google/genai` 2.31.0이다(`package-lock.json` 고정값).
- **채팅**: `npm run eval:ab`(현행을 첫 모델로, 두 모델을 번갈아). 실행 여섯 개. 앞의 다섯은 **E88 이전 도구 구성 기준**이다(E88: 경로 도구의 출발지·수단 한정 인자, 장소 전화번호, 무장애 상세의 이름 인자, 입구 기준 좌우 도구. 이 실행들이 끝난 뒤 main에 들어왔다). 여섯째는 E88이 들어간 트리에서 E88 케이스만 돌린 보충이다(§2-8).

- 나머지 실패: q4 1회 503, x2 1회 20초 회차 시한 초과.

- **생각 차단은 MINIMAL뿐, LOW는 힌트**: 해석에 반영했다. Hydrogen은 MINIMAL을 받지 않아(400) 베르길리우스에서 생각을 0으로 막을 방법이 없고, LOW에서 생각 토큰이 회차마다 66~458로 흔들렸으며 1회는 597로 상한을 넘겼다(§3-3).

## 5. Google SDK

- 쓰는 판: `@google/genai` 2.31.0(`package.json` 범위 `^2.15.0`). 최신은 3.3.0(2026-11-12), 2.x 마지막은 2.32.0이다.
- Gemini 4 계열에 필요한 최소 판은 없다: `generateContent`는 모델 이름을 문자열로 넘기고, 3.3.0의 「gemini-4-hydrogen을 Model enum에 추가」는 Interactions API의 형 정의뿐이다. 2.31.0으로 이번 실측 전부가 돌았다.
- 3.0.0은 깨지는 변경이 있다: Gemini Developer API의 기본 API 판이 `v1beta`에서 `v1`로 바뀌고, Node 22 이상이 필요하다. 그 밖에 `FinishReason`에 `MALFORMED_RESPONSE`, `ThinkingLevel`에 `XHIGH`가 더해졌다. 이 저장소 코드는 `STOP`과만 비교하므로 enum 추가는 동작을 바꾸지 않는다.
- 3.3.0(기본 `v1`)으로 Hydrogen 도구 호출 스트림이 정상으로 돌고, q6 실패도 2.31.0과 똑같이 재현됐다(§3-3). 그러니 업데이트는 이번 판정과 무관하고, 3.x 올림은 기본 API 판 변경을 채팅·추천 칩·베르길리우스 세 경로에서 확인하는 별도 작업으로 둔다.

## 6. 읽는 법과 한계

- 지연은 하루 한 번 잰 값이다. 판정 근거로 쓰려면 다른 날 두 번 더 재야 한다.
- 「낮음」의 17케이스는 1반복이다. 안전·뒤집힘 6케이스는 3반복이다.
- 앞의 다섯 실행은 E88 이전 도구 구성 기준이다. E88 케이스 9개는 3.6-flash와 「낮음」만 1회씩 쟀고, 높음은 재지 않았다. 수치 대조는 여전히 단위를 보지 않고, 지하철 방면 같은 이름은 뽑지 않는다(56의 방면 날조는 사람이 읽어 찾았다).
- 베르길리우스 재료는 한 지점·한 방향이다. OpenAI는 오늘 다시 재지 않았다.
- 비용은 캐시 할인을 빼고 센 상한이다.
- Hydrogen(낮음)으로 채팅을 바꾸는 안은 채팅 루프(`runAgentLoop` 호출부)에 생각 수준 설정을 새로 넣는 코드 변경이 따른다. 하네스의 `@low`는 그 설정을 흉내 낸 것이다.
