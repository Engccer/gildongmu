## 1. 무엇을 어떻게 쟀는가

- **팔 넷, 같은 실행에서 번갈아**: `gemini-3.6-flash`(현행, 첫 항목), `claude-opus-5-5@low`(생각 생략 불가, effort low), `claude-sonnet-5-5@low+between_tools`(생각 끔, effort low), `claude-opus-5-5@medium`(Opus 기본값).
- **케이스**: 하네스 전체 38케이스 × 3반복 = 팔마다 114세션, 합계 456세션. 1반복 실행과 2반복 실행을 한 파일로 합쳤다(반복 번호만 이어 붙임, 같은 커밋 `dbbdcb83`). 원자료 `2026-11-14-claude-chat-models.json`.
- **같게 둔 것**: 지침 정본(`buildChatSystemInstruction`), 도구 선언(Gemini 선언의 JSON 스키마를 그대로 Anthropic 도구로 옮김, 설명·enum·required 보존을 테스트로 확인), 도구 실행기, 루프 상한 6과 빈 답 재시도, 채점기, 재시도 정책(두 회사 모두 재시도 없음). 프롬프트 문구는 바꾸지 않았다.
- **Claude 쪽 설정**: forced `tool_choice`는 400이라 `auto`, 서버 `fallbacks` 안 씀, `refusal`·`max_tokens`는 실패로 기록, 프롬프트 캐싱(지침 끝 + 대화 꼬리). 전송은 스트리밍이고 출력은 비스트리밍과 같다.
- **SDK**: `@anthropic-ai/sdk` 1.6.0. 저장소 `.npmrc`의 `min-release-age = 7` 때문에 1.7·1.8은 설치되지 않는다.
- **단가**(claude-api 스킬 모델 표, 2026-11-14 확인, 1M 토큰당): Opus 5.5 $4/$20, 캐시 읽기 $0.20. Sonnet 5.5 $2/$10, 캐시 읽기 $0.10. 5분 캐시 쓰기는 입력의 1.25배. 3.6-flash는 E86과 같다($0.75/$3.75, 2026-12-31까지).
- **E86 채점기 확인**: E86 원자료 6개를 지금 채점기로 재채점해 바뀐 실행 0건이다.
- **실제 쓴 돈**: Claude 약 $6.6(본 실행 $6.42, 스모크·스트리밍 탐침 약 $0.2). 상한 $12 안이라 회수·팔을 줄이지 않았다. Gemini 3.6-flash $1.35. ODsay 경로 조회는 대중교통 4케이스 × 4팔 × 3반복.

## 잔여 judge

자동 채점 밖의 판독 메모는 §3 표에 적었다. 그 밖에 답을 읽으며 본 것:
- Claude 세 팔은 도구가 0건이나 「제공 안 됨」을 줄 때 「없다는 뜻이 아니라 데이터가 없다는 뜻」이라고 3-state를 분명히 갈랐다(42·43). 3.6-flash도 같았다.
- Sonnet은 22에서 현재 위치가 주어졌는데 「위치를 알지 못한다」고 2회 말했다.

판정: 위원장 판정 대기. 근거: 자동 채점 기준 세 Claude 팔 모두 현행이 지킨 안전 케이스를 놓쳐 스킬 기본 규칙상 전환 불가. 판독 기준 Opus 낮음·Sonnet은 41(도구 밖 응급 기준) 하나만 남는다.
재평가: 41의 응급 기준 안내를 날조로 볼지 정한 뒤 / 채점기 오탐 넷을 고친 뒤 재채점(재호출 불필요) / E86 12월 중순 재측정 때 같은 실행에 Claude를 넣을지.
