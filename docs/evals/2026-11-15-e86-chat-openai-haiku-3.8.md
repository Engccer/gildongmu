## 1. 무엇을 어떻게 쟀는가

- **같은 실행의 팔 여섯, 번갈아**: `gemini-3.6-flash`(현행, 첫 항목), `gpt-6.1-terra@none`·`@low`, `gpt-6-luna@none`·`@low`(`@` 뒤는 `reasoning.effort`), `claude-haiku-5-5@low`(생각은 적응형만 되고 effort low). 1반복 실행 세 번(같은 커밋 `7877ce72`, 지금 브랜치에서는 `514f9e12`)을 한 파일로 합쳤다. 반복 번호만 이어 붙였다.
- **따로 돌린 팔 하나**: `gemini-3.8-flash@low`, 3반복 한 번(커밋 `61141a7f`, 지금 `8e3399a7`, 하네스 코드는 같고 단가표만 더함). 대조군 없이 돌렸으므로 3.6과의 비교는 시간대가 다른 비교이고, 지연은 견주지 않는다.
- **케이스**: 하네스 전체 38케이스 × 3반복 = 팔마다 114세션, 합계 798세션. 진단 케이스는 없다. API 오류는 1건이다(Luna 낮음 41 rep3, 회차 시간 초과 180초).
- **같게 둔 것**: 지침 정본(`buildChatSystemInstruction`, 두 파일의 지침 문자열이 같음을 병합 때 확인), 도구 선언, 도구 실행기(실호출), 루프 상한 6, 채점기, 재시도 없음.
- **OpenAI 러너**(새로 만듦, `src/__ab__/openai-runner.ts`): Responses API, `store: false`로 대화 이력을 매 회차 다시 보낸다. 추론이 켜진 팔은 `reasoning.encrypted_content`를 이어 보낸다. 도구는 Gemini 선언의 JSON 스키마를 `strict: false`로 옮겼다. Terra의 도구 호출은 Responses API에서만 된다(공식 문서). 응답이 완료가 아니거나 거절이면 실패로 기록한다. 깨진 도구 인자 수는 회차에 기록했고 전 팔 0건이다.
- **단가**(1M 토큰당, 2026-11-15 공식 문서): Terra $1/$5(캐시 읽기 $0.05, 쓰기 1.25배), Luna $0.10/$0.50(캐시 읽기 $0.01), Haiku 5.5 $0.10/$0.50(캐시 읽기 0.1배, 5분 쓰기 1.25배), 3.6-flash·3.8-flash 모두 2026-12-31까지 $0.75/$3.75, 2027-01-01부터 $1.50/$7.50.
- **실제 쓴 돈**: Gemini 3.6 $1.36·3.8 $1.31(할인가), OpenAI $0.48(크레딧, 잔액 $92.11·12-08 만료), Anthropic Haiku $0.08(크레딧). ODsay 경로 조회는 `get_transit_route` 125회(3.6 19, Terra 끔 21·낮음 21, Luna 끔 13·낮음 12, Haiku 18, 3.8 21)다. 한 번에 ODsay가 한두 번 나가므로 125~250건, 건당 25원+VAT로 약 3,400~6,900원이다.
- **원자료**: `2026-11-15-e86-chat-openai-haiku-3.8.json`(일곱 팔 합본, 3.8 실행은 `run.separateRuns`에 시각·커밋을 적었다).
